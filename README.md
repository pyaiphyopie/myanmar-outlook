# Myanmar Outlook

A bilingual (English / Burmese) field brief on Myanmar's current situation and five-year outlook (2027–2031).

## Sections

1. **The Present** — political reality, security landscape, humanitarian strain
2. **Economy** — currency, banking, sector shifts
3. **Digital** — connectivity, local platforms, the voice gap
4. **Society** — migration, education, civil society
5. **The 2031 Horizon** — timeline and the two-path fork

## Features

- Dark luxury minimalism (NOX palette: #070707, Electric Cyan, Neon Violet)
- Satoshi + JetBrains Mono typography, Noto Sans Myanmar for Burmese script
- MY/EN language toggle with localStorage persistence
- Scroll fade-in animations, nav active highlighting
- Responsive layout

## Note

Burmese copy is machine-assisted translation. Native editorial review recommended before public distribution, especially political-reality and 2031 sections.
